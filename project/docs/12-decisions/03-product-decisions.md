# Decisiones de producto, UX, negocio y roadmap

| ID | Decisión | Resultado cerrado |
| --- | --- | --- |
| ADR-008 | Roadmap operativo y orden de construcción | VipWeb se construirá de dentro hacia fuera: documentación, estructura, core, datos, permisos, evidencias, después experiencia y módulos visibles. |
| ADR-010 | Gamificación equilibrada integrada | VipWeb integrará gamificación equilibrada desde la base, mediante eventos y reglas simples, sin rankings, rachas agresivas ni presión. |
| ADR-011 | Experiencia visual cálida, tecnológica y acompañante | VipWeb tendrá una experiencia moderna, clara, cálida y tecnológica, con acompañamiento constante, gamificación discreta e IA útil no invasiva. |
| ADR-012 | Ambición inicial del producto | VipWeb será un ecosistema modular escalable, inicialmente controlado, preparado para convertirse en plataforma comercial sin cargar el MVP con SaaS completo. |
| ADR-013 | Modelo de negocio inicial | VipWeb usará un modelo freemium modular progresivo: primero base útil y después módulos avanzados, integraciones, IA operativa o capacidades profesionales monetizables. |
| ADR-014 | Alcance del MVP | VipWeb tendrá un MVP de ecosistema guiado: core, identidad, permisos, dashboard, onboarding, módulos iniciales, progreso ligero, IA básica, admin mínimo, eventos, auditoría y evidencias. |
| ADR-016 | Dashboard como primer módulo funcional real | El primer módulo visible será el Dashboard, centro de control del ecosistema, continuidad del usuario, módulos, progreso, estado e IA básica. |
| ADR-017 | Onboarding guiado progresivo | VipWeb tendrá onboarding progresivo para explicar el ecosistema, captar contexto mínimo, activar módulos iniciales y llevar al Dashboard con progreso. |
| ADR-018 | Administración mínima del MVP | VipWeb incluirá un panel Admin mínimo para usuarios, módulos, permisos, auditoría, evidencias, Doctor y estado del ecosistema. |
| ADR-022 | Sistema visual y componentes MVP | VipWeb usará un sistema visual propio, ligero y modular con HTML semántico, CSS organizado, tokens, componentes reutilizables y JavaScript vanilla. |
| ADR-024 | Backlog ejecutable y Sprint 0 | VipWeb ejecutará Sprint 0 para estructura, documentación mínima, ADRs, catálogos JSON, scripts, configuración WAMP, migraciones, seeds, Doctor, evidencias, registro operativo local y backups. |
