# 01 Domain Terms

| Término | Definición | Regla |
|---|---|---|
| User | Persona autenticada o registrable del ecosistema. | Borrado lógico y roles explícitos. |
| UserContext | Preferencias y contexto usable por experiencia acompañada. | Relación 1:1 con User. |
| OnboardingSession | Proceso guiado inicial. | Puede abandonarse o completarse. |
| Notification | Mensaje interno del sistema. | Debe vincularse a usuario. |
| ProgressRecord | Registro de progreso derivado de evento o ajuste auditado. | No puntos sin fuente. |
| Achievement | Logro versionable con código único. | Condición trazable. |
